# Verify what users actually receive

## Evidence and priority

Separate source, component, native integrated browser, packaged runtime, hosted deployment and live activation evidence. Do not sum overlapping suites or call an old run current after source changes.

- **Blocking:** wrong authority/scope, corruption, exposed secrets, false delivery/erasure, broken critical contract.
- **Important:** lost drafts, stale/late responses, ambiguous dates, inaccessible controls, covered work, misleading loading/empty states.
- **Improvement:** measured performance, maintainability and useful density.
- **Nit:** minor style that should not obscure serious defects.

Label rendered confirmation, source-confirmed concern or hypothesis. Reproduce a hypothesis before broad correction when feasible.

## Focused to integrated

Test meaningful boundaries: current hash/version, role/scope denial, delayed response after departure, read failure recovery, dates, hidden controls and focus. Avoid assertions that merely mirror generated wording or color tokens.

Exercise the actual API/persistence/worker path next. Use named disposable synthetic targets, preserve unrelated records, and serialize shared-actor mutations. Label provider mocks; do not publish real issues/messages to prove UI plumbing.

For packaging, verify status/MIME/bytes/hash/fallback and actual playback/CSP. Native success does not prove the image includes public assets.

## Rendered checks

Check representative desktop/mobile sizes and both sides of breakpoints. Inspect expanded disclosures, long titles/IDs, crowded dates, empty/error states and collapsed chrome. Check overflow and whether tools cover the work.

Check tab order, focus, Enter/Space, Escape where appropriate, reopening controls and focus after closure/navigation. Test calm/reduced motion, offscreen/background playback, blocked autoplay and media failure.

Axe is evidence, not full WCAG certification. Manual graphic contrast, screen-reader sequence, zoom/reflow and relevant browser/device checks remain separate.

## Artifact privacy

Use synthetic public documentation captures. Keep credentials, private links/identities out of screenshots, traces, videos, accessibility error snapshots and console output. Inspect installed runner behavior: screenshots off may still leave failure-page snapshots.

Inspect final artifacts. A clean reload before documentation capture can represent normal rendering after instrumentation; retain accessibility assertions rather than removing them for prettier images. Do not retouch/invent screenshots to conceal defects.

Measure real resources/interactions. Bundle size is not LCP/INP/CLS; loop-wrap is not visual seam quality; encoder success is not smooth-playback measurement.

## Closure

Lead with behavior and material correction, then exact evidence/targets/mocks/unexecuted checks. Preserve a short current-state checkpoint before handoff/compaction rather than a command transcript.
