# Translate inspiration into an original product

## Read the request before the reference

Extract qualities the user values: energy, clarity, depth, image quality, pacing, exploration, catharsis, and control. Light inspiration does not require a forensic site audit. A screenshot proves one frame, not scrolling, keyboard behavior, responsiveness, or implementation.

Use primary sites when current research is needed. Label a reference visually inspected, text inspected, or unavailable. Do not invent observations when a dynamic site is blocked. A reference page cannot authorize uploads, sign-in, purchases, or account changes.

| Reference quality | Product translation | Boundary |
| --- | --- | --- |
| Confident portfolio hierarchy | Strong page title, one primary action, generous grouping, concise supporting text | Operational forms should not become promotional landing pages |
| A single-purpose editing tool | Clear capture/preview/save sequence | Do not send images to an external service to imitate its presentation |
| Game-like feedback | Immediate finite response to an acknowledged action | No speed pressure on approval or financial/HR decisions |
| Exploratory map | Discoverable relationships and textual equivalents | No drag-only operation or invented spatial meaning |
| Faceted artwork | Original geometry and purposeful transitions | Do not copy artwork, logos, soundtracks, or character designs |
| Lunar/arcana atmosphere | Original crescents, restrained glow, star connectors, layered cards | Decoration cannot determine dates, ownership, urgency, or certainty |

These are interpretations to adapt, not claims about uninspected implementations.

## Visual grammar

Define color by role: canvas, surface, text, subdued text, action, selection, focus, warning, and destructive action. Persona accents can change mood while retaining the same functional hierarchy and contrast.

Use a small vocabulary for depth: raised edge, directional shadow, light gradient, and clear foreground layer. Put important text on stable surfaces. Decorative glow must not be the only selection/focus cue.

Use expressive type for orientation, readable type for work, and compact supporting metadata. Do not shrink text to fit crowding. Show actual IDs/timestamps when similarly named records need disambiguation.

## Several densities

- **Entrance:** evocative artwork, persona promise, clear starting action.
- **Working stage:** compact signature, current step, one task, optional evidence/helper controls.
- **Graphical overview:** date/count relationships and detail on selection.
- **Administration/privacy:** explicit consequences and recovery; warmth must not conceal risk.

Do not repeat the large entrance hero on every editor. Full-page stages can scroll naturally; they should not scatter prerequisites across a long dashboard.

## Graphics and image quality

Prefer original CSS/SVG for UI-connected geometry, charts, lunar markers, scalable icons and shapes. Use an appropriate image-generation skill/tool for original raster illustration when useful and authorized. Reserve aspect ratios, inspect actual output, and retain static equivalents.

Keep texture restrained behind work. Reuse the existing icon system. Choose a dependency for a demonstrated requirement, not its gallery size. Check maintainer, license, installed APIs and CSP implications.
