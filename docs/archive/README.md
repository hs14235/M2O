# Planning archive

These are the dated planning, review and coordination records written while M2O was built in phases between October 1 and October 11, 2026. They are kept for history and are **not** current documentation: statements such as "not yet implemented" or "pending" describe the project at the time they were written.

For the current system, start with the [README](../../README.md), [architecture](../ARCHITECTURE.md), [validation record](../VALIDATION.md) and the [study guides](../study/README.md).
