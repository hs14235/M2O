## October 5 lifecycle review

Actual LinkedIn consent and account/workspace erasure paths reproduced two gaps with isolated SQLite data; the existing privacy fixture had inserted a destination not created by the real consent service.

- Account erasure clears draft snapshots, but `all([])` previously classified the redacted draft as current. The provider draft service now requires nonempty source snapshots. The regression confirms another authorized publisher sees stale evidence and cannot prepare an exact post from the erased draft.
- Workspace purge originally enumerated destination rows without an association from real LinkedIn consent, so erasing its only workspace retained credentials. Consent and authorized later use now associate the active workspace under current authority and connection locks. The shared purge captures binding/proposal references and locks each connection before deciding whether another active workspace needs it. Real-service regressions prove unshared removal, shared preservation and denial of later use from cached, cleared credentials.

The new owned `tests/test_linkedin_lifecycle.py` has seven PostgreSQL cases covering actual consent→workspace erasure, two-workspace preservation, cached-grant revocation, redacted source denial, confirmed/uncertain in-flight POST→account erasure, and a delayed callback after workspace authority freezes. The current combined six-file provider run passed **135 PostgreSQL tests in 120.36 seconds**, including the final migration chain and these seven cases. Owned Ruff/format checks passed for 12 files and scoped Pyright reported zero errors. No live provider request or shared runtime mutation is involved.

An approved final privacy correction followed that run: private editors/viewers can revoke their own publishing grant, and a removed member can do so through a browser-authenticated account route. Publishing authority remains unchanged. `tests/test_linkedin_disconnect.py` then passed **nine focused SQLite tests** covering demotion, removed membership, other-actor isolation, visitor/inactive/revoked-generation denial, HTTP browser/CSRF behavior and scoped-bearer rejection. These are leaf-correction results after the 135-test run, not a claim that an unchanged full suite was repeated. Scoped lint/format and service type checks passed.
