## Private lifecycle verification

Phase 3 handed over route contracts after 19 combined PostgreSQL implementation tests. Private onboarding/privacy UI is now implemented against those contracts. Administration uses recipient-owned invitations and no longer offers owner-created passwords. `/invite` and `/recover` remove fragment tokens from history, retain them only in memory, and handle initial React StrictMode reads and later hash changes. Existing recipients sign in as the matching account and omit new-password fields from acceptance. New recipients choose credentials and explicitly sign in after acceptance. Recovery instructions remain neutral and operator assisted; reset revokes prior access and returns to sign-in.

The private Privacy & data route reads current authority/version, requests JSON exports without mutation, and requires the current workspace name/password/version for erasure. Pending erasure needs a fresh status and explicit retry. It remains accessible through the known URL when the frozen workspace disappears from ordinary lists. Account erasure preserves sole-owner rejection and reports deactivation/anonymization distinctly from external provider content. Accepted-invitation feedback survives a failed subsequent account refresh.

Local evidence: TypeScript passed, full frontend/API suite **77/77 across 21 files** passed in 17.44 seconds, and production build passed (59 modules; entry 171.98 kB, 55.14 kB gzip; privacy page is lazy loaded). A subsequent privacy correction added meeting visibility to GitHub/Slack preview keys; the affected **13 tests passed**, including both new regressions, and the updated build passed. The full-suite count predates those two added cases; it is not presented as a fresh 79-test command.

The final four private browser cases ran together on the fresh isolated runtime and passed in **18.3 seconds**: recipient-owned signup/export/account erasure; existing-recipient sign-in/acceptance without a password replacement; operator-assisted recovery with old-session and link-replay denial; and private indexing/worker/export/confirmed workspace erasure preserving the other workspace.
